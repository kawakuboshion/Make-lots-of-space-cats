## 🕹️ 操作方法

| キー / 操作 | アクション |
| :--- | :--- |
| **0 ~ 9** | 行動切り替え |
| **左クリック** | 物を置く / 消す |
| **R** | 回転 |
| **WASD** | カメラの移動 |
| **E,Q** | カメラの回転 |
| **マウスホイール** | ズーム |
| **Space** | カメラのリセット |

## 🛠️ 使用技術・ツール
- **ゲームエンジン:** Unity 6000.0.40f1
- **開発言語:** C#
- **BGM・SE:** DOVA-SYNDROME / 効果音ラボ
- **アセット:**
Inca Props (Pixelated Texture)
Low Poly Factory Machine Pack Demo
Free chibi cat
AllSky Free - 10 Sky / Skybox Set

## 📦 実行・インストール方法
<!-- PCにダウンロードして遊ぶゲームの場合の手順を書きます -->
1. [Releases](https://github.com/kawakuboshion/Make-lots-of-space-cats/tree/master/Releases) から最新版のZIPファイルをダウンロードします。
2. ファイルを解凍します。
3. `Make lots of space cats.exe` を実行してゲームを開始します。
